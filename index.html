Исправление ошибок

Правило учителя: n ошибок исправляет код в (n+1)-мерном пространстве.

Выберите число ошибок и нажмите «Запустить». Число измерений выберется само: d = n + 1.

Как исправляются ошибки

Куб развёрнут в таблицу. Жёлтый фон: линия с нечётным числом единиц, в ней есть ошибка. Красный: ошибочный бит. Ярко-зелёный с рамкой: бит, который декодер только что перевернул. Светло-зелёный: уже исправленные биты. Серый фон: проверочные биты. Если клетки мелкие, цифры не показываются, остаются только цвета.
